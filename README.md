# My Portfolio

A "Signal HUD" style developer portfolio — dark, technical, and motion-led, built with React 19, Vite, Tailwind CSS 4, GSAP, Lenis, and Three.js.

Built during the placement training program at [TAP Academy](https://thetapacademy.com/) (full-stack development, AI and augmented reality training).

## Tech Stack

- **React 19** + **Vite** — fast dev server & build
- **Tailwind CSS 4** — via `@tailwindcss/vite` plugin
- **GSAP** (with ScrollTrigger) — scroll-driven animations
- **Lenis** — buttery smooth scrolling
- **Three.js** — 3D hero centrepiece
- **EmailJS** — contact form without a backend

## Getting Started

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
